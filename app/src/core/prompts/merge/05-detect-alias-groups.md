# 识别别名分组（谁和谁是同一个人）

## 背景

本项目**先用纯代码规则**合并了明显的同人（包含关系、版本后缀）：

```
贾宝玉 = 宝玉     ← 代码能判（包含）
贾琏 = 贾琏（修订版） ← 代码能判（后缀）
```

但**昵称、字号、身份称呼**代码判不了：

```
贾琏 = 琏二爷 = 琏二哥哥     ← 需要你
林黛玉 = 黛玉 = 颦儿 = 潇湘妃子  ← 需要你
```

## 角色

你是这部小说的**责任编辑**。下面给你一批人物名（可能还带他们出现过的其他称呼）。
请你找出**哪些名字其实是同一个人**。

## 铁律

1. **宁可漏判，不可错判。** 拿不准就不要并。
   - 尤其小心：不同的人共用姓氏或名字里的一个字（贾宝玉 / 贾环 不是同一个人）
2. **只输出确实是同一人的分组**，单人不用输出
3. 不要脑补原文没写过的称呼
4. 判断依据：正文里明确写"某某，小字某某"、多个称呼在同一场景指代同一人、明确的身份称呼（"琏二爷" = 贾琏）

## 输入

人物名列表（每行一个，格式：`实体id | 主名 | 已知别名`）

## 自检清单

- [ ] 每组里的人**确实是同一个人**吗？（不是同一个姓氏，也不是同一个家族）
- [ ] 有没有把只有一字之差的不同人并在一起？
- [ ] 有没有漏掉明显的昵称？（漏掉可以接受，错并不可接受）
