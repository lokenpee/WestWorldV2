# WestWorld V2 使用说明

> 版本 v1.0 · 2026-10-04
> 目标：导入一本小说 → 自动抽出世界资产与叙事资产 → 编辑 → 看事件网络

---

## 一、跑起来

```bash
cd app
pnpm install
pnpm dev
```

浏览器打开终端里显示的地址（默认 http://localhost:5173）。

> 首次运行前确认已装 **Node.js 22+** 与 **pnpm**。

---

## 二、先配 API Key（必须）

没有 Key 什么都做不了 —— 提取要靠大模型。

1. 点右上角 **设置**
2. 在「API Key」里粘贴你的 **DeepSeek API Key**（在 https://platform.deepseek.com 申请）
3. 点**保存**

⚠️ **Key 以明文存在本机浏览器存储里**。它不会被导出到备份、不会写进日志，但本机的其他脚本能读到 —— 只建议在个人电脑上使用。

顺便可以在同一个界面调**并发数**（默认 3）：越高越快，越容易触发服务商限流。

---

## 三、导入小说

1. 回到 **资产** 页
2. 把 `.txt` 拖进虚线框，或点「选择文件」
3. **先看分章预览**：

   - 如果整本书只切出 1 章 → 说明章节标记不常见，点「按 GBK 重读」试试编码
   - 如果切得乱七八糟 → 这个版本还不能手动改正则，先换一本格式规整的书

4. 确认无误 → 点**「确认并开始提取」**

---

## 四、等它跑完

进度条下方是**实时日志**，能看到每一步在做什么：

```
▶ 逐章提取 开始 · 共 1200 章
  第 1 章 开始
  ✔ 第 1 章 完成（人物 12 · 地点 3 · 节点 8）
  ……
  正在识别别名（AI）…
  正在融合 37 组的字段（AI）…
  第 1/12 批（400 个节点）…
✔ 串联事件线 完成 · 成功 12 · 失败 0 · 累计 ¥9.87
```

- **可以取消**：已完成的章节会保留，下次接着跑
- **可以关标签页**：下次打开会问你要不要继续（不会自动继续，因为继续要花钱）

---

## 五、看结果

跑完后资产页有五个标签：

| 标签 | 内容 |
|------|------|
| **人物** | 人物实体（已合并）。显示层级、别名、身份 |
| **地点** | 地点列表 |
| **事件节点** | 每一章抽出来的事实节点，带原文出处 |
| **事件线** | 同一件事被串成一条线，含起因/经过/结果 |
| **事件网络** | 可视化的事件脉络图（**双击一条线可以下钻看它的节点**） |

### 事件网络怎么看

- **蓝实线框** = 一条事件线；灰色边框 = 这条线已经结束
- **蓝色虚线** = 两条线共享节点（同一件事被两条线引用）
- **绿色虚线** = 共享人物
- **紫色虚线** = 时间区间重叠
- **双击**一条线 → 下钻到它的节点序列

## 六、编辑与舍弃

**点任意一项**，右侧打开编辑抽屉：

- **人物**：改主名、别名、身份、性格、背景、外貌；改层级；**手动归并**两个人物
- **地点**：改名称与描述
- **事件节点**：改事件名、概述、涉及人物
- **事件线**：改名称、起因/经过/结果、状态

改完点**保存**，列表会自动刷新（不需要手动刷新页面）。

**删除**：每行右侧的「删除」。删除会从库里移除，谨慎操作。

**手动归并**：
- 在人物详情里选「并入」目标 → 当前人物会被标记为并入对方
- **不删除**、**可撤销**（点「撤销归并」）、引用会自动回填
- 归并规则：保留对方、当前标记 `mergedInto`、事件线里的引用改成对方

---

## 七、验证抽取质量（重要）

**提示词抽出来的东西对不对，只有人看得出来。**

点工具栏的**「试跑一章」**：

- 左边是原文，右边是抽出来的人物 / 地点 / 事件节点
- 几秒钟出结果，**不写入数据库**
- 不满意就去改提示词（在 `app/src/core/prompts/`），再点一次

**人工判断要点**：

1. **人物有没有漏抽 / 多抽**？
2. **节点是在「记录事实」还是在「下结论」**？—— 后者不该出现
   - ✅ 「贾琏手头忽然宽裕」
   - ❌ 「这是走私案的伏笔」
3. **一段里的多个事实有没有被拆开**？
4. **每个节点有没有带原文出处**（`quote`）？

---

## 八、备份（重要）

纯浏览器方案下，**清理浏览数据 = 编译成果全丢**。

所以：**跑完就导出**。

- 设置 → 数据 → **导出备份（.wwv2）**
- 换电脑 / 重装浏览器后 → **导入备份**
- 导入会**新建一本书**，不会覆盖现有数据
- 备份**不含 API Key**，也不含事件日志

---

## 九、出问题时

| 现象 | 怎么办 |
|------|--------|
| 填了 Key 还是报认证失败 | 检查 Key 是否正确、账户有没有余额 |
| 提取大量失败 | 看日志里的错误类型：429 = 限流（把并发数调到 1）；401 = Key 问题 |
| 事件线乱七八糟 | 提示词需要调；用「试跑一章」反复试 |
| 刷新后回到导入页 | 应该会自动选中上次的书；如果没有，说明库里确实没有书 |
| 页面全白 | 打开浏览器控制台（F12）看报错 |

---

## 十、当前版本的边界

- 只支持 **`.txt`**，不支持 epub / docx / 网页
- **游玩功能还没接**（游玩页只是空壳）—— Director / Editor / Narrator 属于下一阶段
- 事件网络暂不支持手动连线 / 拖动保存布局
- 不支持多人协作、云同步
